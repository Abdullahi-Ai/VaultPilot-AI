## Transition & Post-Production Rules
1. **Pacing Transitions:** Standard cuts between major screens (12 frames cross-dissolve when transitioning between different application pages).
2. **Cursor Motion:** Smooth Bezier-curved mouse motion with subtle yellow click halo (20px radius, 30% opacity) for user focus guidance.
3. **Typography Standards:** Lower-third fonts: Inter SemiBold / Roboto Medium, white text on `#0F172A` (slate-900) 85% opacity cards with 1px border `#334155`.
4. **Hardware Accuracy:** Clearly tag the UI mode as `Emulated NAS (Ready for UGOS Pro iDX6011)` in Shot 04 so judges know hardware tests are scheduled for the assigned hardware window.
